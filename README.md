# Open Cargo Planner

Open Cargo Planner 是一个面向外贸、仓储和物流团队的开源三维装柜与托盘码放规划工具。用户输入产品、托盘和集装箱数据，系统生成可执行的装载方案，回答“分别能装多少、怎么摆、还剩多少、为什么装不下”。

当前仓库包含一个无后台交互原型，用于验证产品流程、结果表达和三维装载体验。原型中的计算结果由浏览器端模拟生成，不代表正式求解器的最优结果。

## 核心场景

- 散装：产品箱直接装入集装箱。
- 托盘：产品先码放到托盘，再将整托装入集装箱。
- 混装：整托和散箱共同装柜（规划能力，原型暂未开放）。
- 多 SKU：同时计算不同产品的装载数量和剩余数量。
- 多柜型：比较 20GP、40GP、40HQ 等柜型的利用率。

## 原型能力

- 散装与托盘模式切换。
- 编辑产品尺寸、数量和重量。
- 选择常见集装箱柜型。
- 设置托盘尺寸与数量。
- 在浏览器中模拟生成方案。
- 查看装载数量、剩余数量、体积利用率和重量利用率。
- 查看可旋转的三维装柜示意和分层结果。

## 本地运行

原型没有后台，也没有构建步骤。

方式一：直接打开 `index.html`。

方式二：在仓库目录启动静态服务器：

```bash
python -m http.server 4173
```

然后访问本地端口 `4173`。

## 正式产品建议架构

```text
Web 前端（TypeScript + Three.js）
             │
             ▼
业务 API（Node.js + TypeScript）
             │
             ▼
求解服务（Java 21）
     ├── xflp
     └── 3d-bin-container-packing
             │
             ▼
PostgreSQL + 异步任务队列
```

详细设计见 [ARCHITECTURE.md](./ARCHITECTURE.md)，产品方向见 [VISION.md](./VISION.md)。

## 正式求解器候选

- `hschneid/xflp`：MIT，支持承重、堆叠组、装卸顺序和轴荷，适合作为现实约束主求解器。
- `skjolber/3d-bin-container-packing`：Apache-2.0，计算快速、接口成熟，适合作为快速求解和对照基线。
- `fontanf/packingsolver`：MIT，C++，求解能力较强，可作为后续深度优化引擎。

## 第一阶段开发范围

1. 产品、托盘和柜型资料管理。
2. Excel 批量导入。
3. 散装与单品托盘模式。
4. 产品旋转、最大载重和顶部承重约束。
5. 异步求解和进度反馈。
6. 三维方案、分层图和装载顺序。
7. Excel/PDF 装柜清单导出。
8. 多个候选方案比较。

## 重要说明

三维装箱属于 NP-hard 问题。正式产品应将结果描述为“在指定计算时间和约束条件下找到的最佳可行方案”，而不是在所有规模下承诺数学意义上的绝对最优。
